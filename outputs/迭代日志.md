## 三、逐代迭代日志

### 史前 · AI 原型（09-16）——「先做出来」的课程起点

- **v0 原型**：与通义千问结对，把「关于我 / 教育 / 项目 / 数字分身 / 技能证书 / 兴趣性格 / 互动 / 联系」八大模块设想一次性铺开，84KB。
- **v0 测试页**：四张球星图片的路径调试页，绿色 = 找到了、红色 = 没找到——最朴素的工程初心。
- **代际意义**：对应 V1 课件「先做出来，再逐步改」。原型的价值不是代码本身，而是把「想要什么」全部可视化，为手工重构提供蓝图。
- **关键决策**：AI 生成的代码虽然「什么都有」，但结构失控、难以维护——由此确立第一代的核心任务：**手工重构，每一行都看得懂、改得动**。

### 第一代 · 奠基（v1.2.x，09-16 ~ 09-17）——课程 V1 阶段核心

**代际使命：把 AI 原型变成自己掌控的 MVP。**

- **v1.2 手工重构**：对 AI 原型「删 1079 行、重写 469 行」，收敛为六大板块（关于我 / 教育 / 项目 / 分身 / 技能兴趣 / 互动联系）。信息密度首次做减法。
- **v1.2.1 样式精修**：42KB 全系列最小体积；首屏排版（副标题、按钮、卡片间距）统一。
- **v1.2.2 弹窗系统**：modal-overlay + 缩放位移入场动画，此后所有详情展示有了统一容器；利物浦球星卡上线。
- **v1.2.3 项目 PDF + chip 标签**：AI4s-PVC 论文 PDF 直链接入；专业/技能标签化展示。
- **v1.2.3pro / Max**：球星卡扩展（配色随球队主题：利物浦红 / 塞尔维亚蓝 / 中国红）；图片懒加载。
- **V1 验收自查对照**（课件标准）：✅ 可预览（本地双击 + 手机尺寸均验证）✅ 内容真实（教育经历、证书、项目均可核验）✅ 结构清楚（访客能快速知道「我是谁、做过什么、能联系我做什么」）✅ 版本已保存并记录下一轮改进重点。

### 第二代 · 互动（v1.3.x，09-17 ~ 09-18）——课程 V2 阶段开始

**代际使命：从「名片」到「可玩」，让页面有声有色。**

- **v1.3.1 ~ v1.3.2**：音乐播放器从无到有再到完善（FM1/FM2 双曲 → 上一首/下一首/状态同步），两次迭代确立交互体系。
- **v1.3.3**：证书数字化——雅思 7.0 / 竹笛十级 / 漫画九级三证从静态文字升级为可点击放大展示。
- **v1.3.3pro**：3D VR 可视化项目通过 iframe 内嵌进项目区，访客可现场拖动；深色主题变体探索（后评估未纳入主线，见《反馈与改进》决策记录）。
- **v1.3.4**：音乐播放器最终形态定型，二代功能全家桶收官。

### 第三代 · 智能与内容（v2.1.x，09-18 ~ 09-20）——课程 V2 阶段深化 + V3 阶段前奏

**代际使命：安全、智能、内容、国际化四线并进。**

- **v2.1.1 安全升级**：DeepSeek API Key 从 HTML 硬编码明文改为 🔑 弹窗设置 + localStorage 浏览器本地存储，密钥永不上传。（V3 课件密钥安全红线的提前实践）
- **v2.1.2 代码瀑布背景**：全屏动态代码瀑布替换 Verlet 物理幕布，3600 帧稳定性仿真验证。
- **v2.1.3 ~ v2.1.5 Trent 数字分身四步进化**：悬浮跟随 → 问答弹窗（流光边框/消息流/快捷 chips）→ Apple Intelligence 风格图标 → 知识库外挂 `trent-knowledge.js`（28 条个人知识，改数据不动代码）。对应 V1 课件「数字分身先做静态占位、后续接入真实能力」的路线图。
- **v2.1.6 3D 旅行地球**：Canvas 正交投影、8772 陆地点阵、惯性拖转、6 倍缩放——零外部依赖纯原生实现；地点照片标记样式参考旅行手账海报。**同版本建立 CHANGELOG 逐版日志制度**（每次改动必记录、必仿真验证）。
- **v2.1.7 全站三语**：简/繁/英实时切换（167 键 × 3 字典 + 知识库三语 + AI 提示词随语言切换），选择持久化。
- **v2.1.8 反馈墙**：五星评分（App Store 同款交互）+ 公示墙 + textContent 渲染防 XSS 注入——课程 V3「反馈入口」的第一次落地（本机 localStorage 版）。
- **v2.1.9 三代收官**：2023 旅行照片 22 张导入；地球弹窗支持视频播放（若尔盖草原首条视频，HEVC→H.264 转码）。

### 第四代 · 全端体验（v2.2.x，09-20 ~ 09-24）——课程 V3 完成 + V4 迭代

**代际使命：从桌面单端到全设备、从本机到云端、从发布到反馈驱动迭代。**

- **v2.2.0 三端响应式**：手机（≤640px）/ iPad（641-1024px）/ 电脑（>1024px）三档断点，纯 CSS 媒体查询；刘海屏安全区 `env(safe-area-inset)` 7 处覆盖；`100svh` 解决移动浏览器地址栏遮挡；触摸目标 ≥44px；Trent 弹窗改底部抽屉。
- **v2.2.1 云端反馈墙（课程 V3 阶段完成标志）**：
  - 反馈写入 Supabase 云端（表 `feedback`），所有访客实时共享同一面反馈墙，20 秒自动拉取，失败可重试且输入不丢失；
  - 未配置密钥时自动降级为 localStorage 本机模式（向后兼容）；
  - PDF 下载二次确认弹窗（HEAD 探测真实文件大小）、邮箱卡片跨行、手机端内容居中。
- **09-24 补丁（课程 V4 阶段：反馈驱动迭代）**：
  - 教育经历改时间正序（小学 → 大学，按成长顺序自上而下）；
  - 修复音乐播放中按钮符号消失（⏸/▶ 状态）；
  - 雅思标签补全英国国旗 🇬🇧（原区域指示符多数设备渲染为空白，共 4 处）。
- **演进史 + 历史归档**：`history/` 收录 4 代 23 个可访问版本；**10 个文件 11 处硬编码 DeepSeek Key 全部脱敏**（`sk-REDACTED` 占位）；新增演进史页面与主站横幅入口。
- **导航顺序修正 + 网站更名**：「律照楠 | Personal Homepage」→「Trent Lyu | Personal Homepage」（与 Trent Intelligence 分身品牌统一，i18n 三语 + 静态 title 同步）。
- **语言选择底部抽屉 + 移动端强化**：首访语言弹窗改为底部抽屉（0.6s 延迟弹出 + 竞态保护，避免与首屏加载争抢注意力）；音乐按钮触控 44px；`body` 底部让位；iPad 弹窗限宽。

## 四、版本管理与过程证据（对应课件「每次提交都能解释自己的决定」）

项目没有止步于「能用」，而是建立了三层的版本证据链：

1. **文件级快照**：每个版本一个独立 HTML 文件（v1.2 → v2.2.1），`index.html` 始终指向最新版；Git 仓库保存全部提交节点。满足 V4 课件「Always keep a version you can go back to」。
2. **制度级日志**：`CHANGELOG.md` 自 v2.1.6 起逐版必填（改动内容 + 实现说明 + 验证结果），小到一次 emoji 修复也有记录。
3. **归档级演进史**：`history/` 目录将 23 个历史版本整理为线上可访问的档案（含版本横幅、脱敏处理、资源路径重写），并配套演进史页面（四代分组 + 代际总结 + 里程碑标注）。
