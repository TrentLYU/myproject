## 一、设计原则总述

课程开篇的四句执行心法贯穿了全部 23 个版本的迭代：

| 课程心法 | 项目实践 |
| --- | --- |
| 先做出来，再逐步改 | v0 千问原型先把八大模块全部铺开，再在第一代手工收敛为六大板块 |
| 一次改一类问题 | 每个小版本只解决一类问题（样式精修 / 弹窗 / 音乐 / 证书 / 地球 / 三语各自成版），从不一次性大改 |
| 发布后认真听取反馈 | v2.2.1 发布后进入 V4 迭代周期，全部改动由反馈与自测证据驱动（见《反馈与改进》） |
| 每次提交都能解释自己的决定 | CHANGELOG 逐版记录「改了什么 + 为什么 + 验证结果」，23 版全部可追溯 |

贯穿全程的审美取向：**Clarity > Complexity（清晰胜过复杂）**——V4 课件「More Features ≠ Better Product」的自觉实践。

## 二、技术基线选型（对应 V1 课件技术栈章节）

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 站点形态 | 纯静态 HTML / CSS / JS，零构建依赖 | V1 课件：以「能跑、能发布」为第一优先级；无 Node 环境、无编译，双击即开、随处可部署 |
| 结构组织 | HTML + 独立 JS（`globe.js` / `i18n.js` / `trent-knowledge.js` / `travel-places.js`），CSS 内联于单文件 | 三件套职责分离（结构/样式/行为）；用户可编辑数据全部外挂，改内容不动代码 |
| 发布 | GitHub Pages 项目页（trentlyu.github.io/myproject/） | 静态托管零成本；资源全部使用相对路径以适配子路径 |
| 反馈后端 | Supabase（PostgreSQL）+ 前端 REST 直连 | V3 课件公式「静态托管 + 外部后台 = 可以保存数据」；浏览器直接向 Supabase 发请求，GitHub Pages 只负责发文件 |
| 版本控制 | Git 仓库 + 每版独立 HTML 文件 + `history/` 归档 | 不依赖单一手段，文件快照让任何旧版可直接线上访问 |

**关键取舍**：多次评估后放弃引入 React / Tailwind 等现代栈——3D 地球用 Canvas 正交投影纯原生实现（8772 点阵、惯性拖转、6 倍缩放），i18n 用自研 193 键 × 3 字典引擎。零依赖使整站保持「打开即用」，也避免了 V2 课件提示的「组件库重依赖陷阱」。

## 四、核心功能设计思路（每个功能：目标 → 想法来源 → 借鉴层级 → 实现要点）

> 借鉴层级采用 V2 课件 Level 1（整体灵感）/ Level 2（设计元素）/ Level 3（组件）/ Level 4（模板）分类标注；术语引用 V2 课件 Part 5。

### 4.1 设计系统（CSS 变量 + 卡片 + 按钮语言）—— v1.2 确立

- **目标**：让后续 20+ 个版本「改得动、不散架」。
- **想法来源**：shadcn/ui 的组件化理念（Level 1——学「现代网页不每个按钮从零写」的思路，不引入其代码）。
- **实现**：CSS 变量统一色彩/圆角/阴影；`btn--primary` / `btn--ghost` 双态按钮语言；卡片（Card）+ 网格布局打包同粒度信息；标题 → 章节 → 卡片 → 正文的 Typography 四级层级；有意识的 Whitespace 控制节奏。全部效果自研，保持零依赖。

### 4.2 弹窗系统（modal-overlay）—— v1.2.2

- **目标**：证书、球星、问答、反馈等所有「详情展示」共用一个容器，交互心智统一。
- **想法来源**：Level 2（设计元素）——各类作品集网站的灯箱/弹窗范式。
- **实现**：统一遮罩 + 缩放位移入场动画（cubic-bezier 弹性曲线）；✕ / 点遮罩 / Esc 三种关闭方式成为全站惯例。

### 4.3 音乐播放器 —— v1.3.1 → v1.3.4 三次迭代定型

- **目标**：让页面「有声」，但不打扰阅读。
- **想法来源**：个人音乐收藏（FM1/FM2 双曲）+ 常见博客挂件（Level 1）。
- **演进**：浮动播放条 → 完整交互（上/下一首、状态同步）→ 最终形态（贴底横条、移动端触控 ≥44px、`body` 让位不遮页脚）。一次只改一类的典型示范。

### 4.4 证书数字化 —— v1.3.3

- **目标**：技能主张「可核验」（V1 课件：内容真实性，不虚构）。
- **实现**：雅思 7.0 / 竹笛十级 / 漫画九级三张证书从文字升级为可点击放大展示，复用 modal 体系。

### 4.5 3D VR 项目内嵌 —— v1.3.3pro

- **目标**：项目展示从「描述」变「现场可交互」。
- **实现**：科研可视化成果（3D VR 传热过程）以 iframe 内嵌项目区，访客直接拖动。教训：子路径下资源引用 + 全角括号文件名曾导致线上 404（见问题 P7）。

### 4.6 Trent 数字分身四步进化 —— v2.1.3 → v2.1.5

- **目标**：落实 V1 课件「数字分身/对话入口原型：先做静态占位，后续接入真实能力」。
- **想法来源**：Apple Intelligence 图标气质（Level 1 灵感借鉴，图标为自绘渐变交织环，非复制素材）。
- **演进**：右侧悬浮跟随（极慢速 EASE=0.016）→ 问答弹窗（流光边框 / 消息流 / 快捷 chips）→ Apple Intelligence 风格图标 → **知识库外挂** `trent-knowledge.js`（28 条个人知识：宠物、最爱球星、旅行、作息……改数据不动代码），未命中走兜底话术引导联系本人；后续升级接 DeepSeek API（密钥安全见 P1）。

### 4.7 3D 旅行地球 —— v2.1.6（项目最大自研功能）

- **目标**：把 137 张旅行照片从「相册」变成「可探索的世界」。
- **想法来源**：旅行手账海报的圆形照片贴纸（Level 1 整体灵感）+ 各类 3D 地球库的视觉感受（Level 2——借鉴效果气质，全部代码自研）。
- **实现**：Canvas 正交投影纯原生实现，零外部依赖；Natural Earth 110m 数据生成 8772 陆地点阵；鼠标/手指惯性拖转，闲置 2.6s 自转；滚轮/双指/按钮三方式缩放至 6 倍；地点小圆照片标记（白色描边、转背面自动隐藏）→ 详情卡片 → 全屏灯箱 → 视频播放（HEVC 自动转码 H.264）。
- **数据驱动**：地点配置全部外挂 `travel-places.js`（含三语 name/sub/desc 结构），9 天内 4 批导入 121 张照片只需改数据文件。

### 4.8 全站三语 i18n —— v2.1.7

- **目标**：面向真实访客群体（家人朋友用简中、港理工场景需要英文）。
- **实现**：自研 i18n 引擎（`data-i18n` 系列标记 + 193 键 × 3 字典）；知识库与旅行地点三语；DeepSeek 系统提示词随语言切换；opencc 自动转换繁中 + 人工校对误转（如「型别→類型」）；首访语言选择（后在 V4 迭代中重构为底部抽屉，见《反馈与改进》）。

### 4.9 反馈墙 —— v2.1.8 → v2.2.1（详见《反馈与改进》）

- **想法来源**：App Store 评分交互（Level 1——「悬停预览 + 语言化评语」的交互感受，用自己的视觉实现）。
- **演进**：五星评分 + 公示墙（localStorage 本机版）→ Supabase 云端实时共享（20s 自动拉取）。

### 4.10 三端响应式 —— v2.2.0

- **目标**：「不是缩小的桌面版，而是重排的手机版」。
- **方法论**：V1 课件「移动优先」——手机（≤640px）/ iPad（641-1024px）/ 电脑（>1024px）三档纯 CSS 断点，无需 JS 判断设备。
- **关键实现**：`100svh` 动态视口解决移动地址栏遮挡；刘海屏 `env(safe-area-inset)` 覆盖 7 处悬浮层；输入框统一 16px 防 iOS 聚焦放大；Trent 弹窗手机端改底部抽屉（78dvh 上滑）；触摸目标 ≥44px（Apple HIG）。

### 4.11 网站演进史归档 —— 09-24

- **目标**：把「迭代过程」本身变成作品的一部分（过程证据 = 产品内容）。
- **实现**：`history/` 收录 23 个版本全部线上可访问；演进史页面按四代分组，每代有代际进步总结 + 里程碑标注 + 双链接（访问 / 源码）；主站项目区与分身之间放置渐变横幅入口（Gradient + Hover 上浮动效）。

## 六、问题与解决（Problems occurred and solved）

> 每个问题按「现象 → 原因理解（why）→ 解决（how）→ 验证」记录；对应 V4 课件「AI says done ≠ task is finished」——所有修复均以回归验证收尾。

### P1 · AI 生成代码失控（v0 → v1.2，最重大的问题）

- **现象**：千问原型 84KB「什么都有」，但结构混乱、重复代码多、牵一发动全身。
- **原因理解**：一次性生成缺乏信息架构设计；「功能全」与「可维护」是两件事。
- **解决**：手工重构——删 1079 行、重写 469 行，收敛为六大板块；确立 CSS 变量设计系统与 modal 统一容器。
- **验证**：v1.2 系列 6 个小版本连续迭代未再出现结构性返工。

### P2 · API Key 硬编码泄露风险（v1.2 ~ v1.3.3pro）

- **现象**：早期版本把 DeepSeek Key 明文写在 HTML 里，且站点即将公开发布到 GitHub Pages。
- **原因理解**：前端代码全部公开可见，任何硬编码凭据等于泄露；V3 课件红线「secret 永不进前端」。
- **解决**：v2.1.1 改为 🔑 弹窗输入 + localStorage 浏览器本地存储，密钥永不上传；归档历史版本时对 10 个文件 11 处历史 Key 全部脱敏。
- **验证**：`sk-[a-zA-Z0-9]{20,}` 全仓正则扫描零残留；脱敏页面仍可正常打开（语法完整）。

### P3 · 移动端 PDF 自动下载打扰（v2.2.1）

- **现象**：部分手机浏览器打开项目区即触发论文 PDF 下载，访客莫名其妙收到 9.6MB 文件。
- **原因理解**：页面加载时 iframe 预载 PDF，移动端浏览器的处理方式是直接下载而非预览。
- **解决**：移除自动加载；「⬇ 下载 PDF」改为确认弹窗（HEAD 请求探测真实大小后再决定），主动预览/新窗口打开保留为访客主动操作。
- **验证**：check-221 结构检查 48/48，PDF 确认流程用例通过。

### P4 · 邮箱地址溢出卡片（v2.2.1）

- **现象**：长邮箱地址在联系卡片中溢出边界。
- **原因理解**：连续英文字符串不会自动换行。
- **解决**：邮箱卡片跨整行（`contact__item--wide`）+ `overflow-wrap: anywhere`。
- **验证**：三端截图核验不再溢出。

### P5 · 移动浏览器 100vh 地址栏遮挡（v2.2.0）

- **现象**：手机端首屏底部按钮被浏览器地址栏遮住一截。
- **原因理解**：`100vh` 按最大视口计算，移动端地址栏收起/展开时视口高度动态变化。
- **解决**：改用 `100svh` 动态视口单位；悬浮层全部适配 `env(safe-area-inset-*)`。
- **验证**：真机滚动测试首屏完整可见。

### P6 · iOS 输入框聚焦页面放大（v2.2.0）

- **现象**：iPhone 上点击反馈表单，整个页面被放大。
- **原因理解**：iOS 对字号 <16px 的输入框聚焦时会自动缩放。
- **解决**：表单输入统一 16px。
- **验证**：iPhone Safari 实测聚焦不再放大。

### P7 · 项目区 3D VR iframe 线上 404（09-24 修复）

- **现象**：本地正常，线上两个 3D VR 页面空白。
- **原因理解**：① 引用路径带了已废弃的 `assets/` 前缀；② 文件名中全角括号「（heating process）」与代码中的半角括号不一致——本地服务器容错、线上区分大小写与全半角。
- **解决**：逐一修正为根目录真实文件名（含全角括号）。
- **验证**：两个文件本地 HTTP 200，`src="assets/` 残留清零。

### P8 · 灯箱「点击任意处关闭」吃掉视频控件（v2.1.9 当晚修复）

- **现象**：视频刚打开就被关闭，无法操作播放控件。
- **原因理解**：点击事件冒泡到灯箱遮罩的「点击关闭」监听器。
- **解决**：改为只有点击遮罩空白处或大图本体才关闭；同时为旧版页面动态补播放器元素（替代易被拦截的 window.open）。
- **验证**：视频用例 11 项仿真全过。

### P9 · 播放中按钮符号消失（09-24 补丁）

- **现象**：音乐播放状态下播放/暂停按钮变成空白。
- **原因理解**：`updateUI()` 在播放态错误地把按钮内容置为空字符串。
- **解决**：播放中显示 ⏸、暂停/未播放显示 ▶。

### P10 · 国旗 emoji 渲染为空白（09-24 补丁）

- **现象**：雅思标签处的英国国旗在多数设备上不显示。
- **原因理解**：误用了「区域指示符」单字符 🇬，它只是 Unicode 组合部件，并非完整国旗。
- **解决**：补全为双字符组合 🇬🇧，共 4 处（默认文本 + 三语字典）。
- **验证**：多设备渲染核验。

### P11 · 首访语言弹窗与首屏加载「争抢注意力」（09-24 第四次提交）

- **现象**：页面刚打开就被居中语言弹窗打断，观感突兀。
- **原因理解**：两个「第一印象」同时发生——首屏渲染与语言选择互相干扰。
- **解决**：重构为底部抽屉（sheetIn 上滑 + iOS 把手 + 安全区适配）；延迟约 0.6s 待首屏渲染完成再弹出；等待期间用户若已手动切换则不再打扰（竞态保护）；对 history/ 归档页面向后兼容。
- **验证**：CSS 花括号 512 对平衡；语言弹窗 9 项结构检查全过；i18n.js 语法校验通过。
